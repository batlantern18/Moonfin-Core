## Agent skills

### Issue tracker

Issues are tracked as GitHub issues in [batlantern18/Moonfin-Core](https://github.com/batlantern18/Moonfin-Core). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: a root `GLOSSARY-MAP.md` pointing to per-package `GLOSSARY.md` files, with per-context ADRs at `packages/<name>/docs/adr/`. See `docs/agents/domain.md`.
