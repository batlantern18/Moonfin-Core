## Product reference

`gboard_android_tv_recreation_spec.md` defines the feature set this keyboard is meant to have, modelled on Gboard for Android TV: IME lifecycle and latency budget, compact floating window with `horizontalAlignment`, the four input-type modes, top utility bar, D-pad and long-press interactions, voice typing, predictions and email suggestions, language support, companion remote, settings, and accessibility. Read it before proposing or scoping features. It is the reference for what to build, not the plan for building it.
